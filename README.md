# Transformer-Oil-Temperature-and-Load-Monitor
ESP32-based Smart Transformer Oil Temperature and Load Monitor System

## Project Overview
A smart transformer monitoring system using ESP32 that monitors temperature and current, classifies operating conditions (Safe, Warning, Critical), activates LEDs and buzzer alerts, and supports data buffering for future cloud integration.

## Features
- ESP32-based monitoring
- Temperature and current sensing (simulated using potentiometers)
- Safe / Warning / Critical status detection
- LED and buzzer alerts
- Moving average filtering
- Consecutive reading validation
- Sensor fault detection
- Store-and-forward buffering

## Hardware
- ESP32 DevKit C V4
- Potentiometers
- LEDs
- Buzzer
